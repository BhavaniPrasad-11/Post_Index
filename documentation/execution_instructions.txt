1. OVERVIEW
This package contains the complete, working Malayalam Positional Inverted Index
constructed from official Malayalam Wikipedia article dumps.

The architecture strictly adheres to the course requirements:
- Vocabulary (lexicon) is loaded and maintained in Main Memory (RAM) for O(1) lookups.
- Positional postings lists are stored persistently on Secondary Storage (SQLite B-tree).
- Query operations fetch postings on-demand from disk.
- Token positions are 1-based sequential integers in the cleaned document text.
- Positional intersection supports multi-word exact phrase search.

4. STEP-BY-STEP EXECUTION COMMANDS
===============================================================================

A. VIEW COLLECTION STATISTICS:
  python main.py stats

B. SEARCH A SINGLE MALAYALAM TERM (Displays CF, DF, and positional postings):
  python main.py search-term "കേരളം" --limit 5
  python main.py search-term "മലയാളം" --limit 5
  python main.py search-term "ഇന്ത്യ" --limit 5

C. EXACT PHRASE SEARCH VIA POSITIONAL INTERSECTION:
  python main.py search-phrase "കേരള സാഹിത്യ അക്കാദമി" --limit 5
  python main.py search-phrase "ഇന്ത്യൻ സംസ്ഥാനമായ" --limit 5
  python main.py search-phrase "പ്രധാന നഗരം" --limit 5

D. DISPLAY RARE MALAYALAM TERMS (DF = 1):
  python main.py rare-terms --limit 10

E. RUN THE AUTOMATED UNIT TEST SUITE (5 Test Cases):
  python main.py test
  # or directly:
  python tests/test_indexer.py -v

F. RUN COMPREHENSIVE 12-RULE INTEGRITY VALIDATION:
  python scripts/validate_index.py

G. LAUNCH INTERACTIVE CONSOLE MENU:
  python main.py interactive

H. REBUILD THE INDEX FROM SCRATCH (Optional):
  # Download dataset dump if needed:
  python src/dataset_downloader.py
  # Build index for 5,000 articles:
  python scripts/build_index.py --max-docs 5000
  # Generate all output reports:
  python scripts/generate_reports.py
